# MediFlow AI

## AI-Based Smart Hospital Resource Management and Patient Readmission Risk Prediction System

### Tagline

Predict. Prioritize. Care.

## Project Type

MCA 3rd Year Minor Project

## University

Manipal University Jaipur

## Technology Stack

- Android
- Kotlin
- Jetpack Compose
- Material 3
- FastAPI
- Python
- PostgreSQL
- Machine Learning
- Data Science
- DAA Algorithms

## Project Objective

MediFlow AI is an academic healthcare technology prototype that combines:

- Hospital resource management
- Patient management
- Doctor management
- Appointment scheduling
- Bed management
- Patient readmission risk prediction
- Data Science
- Machine Learning
- DAA-based optimization
- Hospital analytics

> This application is an academic prototype and is not intended for clinical diagnosis or medical decision-making.
